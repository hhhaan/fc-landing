**머신 제어**는 Active Roast 화면에서 로스터의 **화력(Heater)·팬(Fan)·드럼(Drum)** 을 원격으로 조작하는 기능입니다. 지원 머신에서는 **Auto Heat (PID)** 로 목표 BT를 유지할 수도 있습니다.

:::note[플랜]
**Pro+** 및 **Enterprise**(내부 `team` / `tester` 포함)에서만 사용할 수 있습니다. Pro·체험·무료에서는 제어 패널이 표시되지 않습니다. → [요금제](/service/plans/)
:::

## 전제 조건

1. Pro+ 이상 구독
2. [머신 연동](/machines/) 완료 — 사이드카가 연결되고 실시간 온도가 들어와야 함
3. 해당 모델이 **쓰기(control)** 가능한 채널을 보고해야 함  
   (온도 읽기만 되는 머신은 제어 패널이 나타나지 않거나 채널이 N/A)

## Active Roast에서 조작

1. 로스팅 세션을 시작하고 머신에 연결합니다.
2. 그래프 옆 **Machine Control** 패널을 펼칩니다.
3. 세로 fader로 값을 조정합니다.
   - **Heater** — 화력
   - **Fan** — 풍량
   - **Drum** — 드럼 속도
4. 손을 떼면(또는 키 조작 후) 사이드카로 명령이 전송됩니다. 기기가 따라오지 않으면 경고가 표시됩니다.

### 미지원 채널

슬롯은 항상 **Heater / Fan / Drum 3칸**입니다.  
머신이 지원하지 않는 채널은 **disabled** 로 두고 값 `—` · 라벨 **N/A** 로 표시합니다. 레이아웃이 모델마다 흔들리지 않게 하기 위함입니다.

### Auto Heat (PID)

- 머신·레지스트리 설정이 PID(화력 쓰기 + 게인)를 지원할 때만 패널 하단에 표시됩니다.
- **Hold BT at target** 을 켜면 소프트웨어 PID가 화력을 잡고 목표 온도(SV)를 유지합니다.
- PID가 동작 중이면 Heater fader는 **PID** 로 잠깁니다(수동과 소유권 충돌 방지).
- 배출·세션 종료 시 설정에 따라 화력을 유지하거나 0으로 내립니다.

## 지원 범위

- 제어 가능 여부는 **모델·프로토콜 맵**에 따라 다릅니다. 읽기 전용 연동만 되는 경우 제어는 불가합니다.
- 모델별 연결 방법은 [머신 연동 개요](/machines/), [Modbus](/machines/modbus/), [Phidget](/machines/phidget/) 을 참고하세요.
- 지원 채널 목록이 예상과 다르면 [문의](/support/contact/)에 제조사·모델·통신 방식을 알려 주세요.

## 문제 해결

| 증상 | 확인 |
|------|------|
| 제어 패널이 안 보임 | Pro+ 여부, 머신 연결·writable 상태, 플랜 로딩 |
| 채널이 전부 N/A | 해당 프리셋에 쓰기 맵 없음 — 읽기 전용 연동일 수 있음 |
| 값을 올려도 기기가 안 움직임 | 로스터 본체 원격 제어 허용, 인터락, 조작반 로컬 모드 |
| PID가 안 보임 | heater 쓰기 + PID 게인이 없는 모델 |
| “기기가 명령을 반영하지 않았습니다” | 연결 끊김, 쓰기 거부, 범위 초과 — 사이드카·머신 로그 확인 |

연결 자체 문제는 [연동 문제 해결](/machines/troubleshooting/)을 먼저 보세요.
