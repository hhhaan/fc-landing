title: マシン制御

**マシン制御**は Active Roast 画面からロースターの **火力（Heater）・ファン（Fan）・ドラム（Drum）** を操作する機能です。対応機では **Auto Heat（PID）** で目標 BT を維持できます。

:::note[プラン]
**Pro+** および **Enterprise**（内部 `team` / `tester` を含む）のみ。Pro・トライアル・無料では制御パネルは表示されません。→ [料金プラン](/ja/service/plans/)
:::

## 前提

1. Pro+ 以上
2. [マシン接続](/ja/machines/) 済み — サイドカー接続とライブ温度
3. モデルが **書き込み可能な control** チャンネルを報告すること  
   （温度読み取りのみの連携ではパネル非表示、または N/A）

## Active Roast での操作

1. 焙煎セッションを開始しマシンを接続します。
2. グラフ横の **Machine Control** パネルを開きます。
3. 縦 fader で値を調整します。
   - **Heater** — 火力
   - **Fan** — 風量
   - **Drum** — ドラム速度
4. 離すと（またはキー操作後）サイドカーへ送信されます。機器が追従しない場合は警告が出ます。

### 非対応チャンネル

スロットは常に **Heater / Fan / Drum の 3 枠**です。  
非対応チャンネルは **disabled**、値 `—`、ラベル **N/A** で表示し、レイアウトが機種ごとに崩れないようにします。

### Auto Heat（PID）

- PID（火力書き込み + ゲイン）対応機のみパネル下部に表示されます。
- **Hold BT at target** をオンにするとソフトウェア PID が火力を握り目標温度（SV）を維持します。
- PID 動作中は Heater fader が **PID** でロックされます。
- 排出・セッション終了時の火力は設定（hold / zero）に従います。

## 対応範囲

- 書き込み可否は **モデルとレジスタ／能力マップ**次第です。読み取り専用連携では制御できません。
- 接続手順: [概要](/ja/machines/)、[Modbus](/ja/machines/modbus/)、[Phidget](/ja/machines/phidget/)。
- チャンネルが想定と違う場合は [お問い合わせ](/ja/support/contact/) にメーカー・モデル・通信方式を添えてください。

## トラブルシューティング

| 症状 | 確認 |
|------|------|
| 制御パネルが出ない | Pro+ か、接続・writable、プラン読み込み |
| すべて N/A | 書き込みマップなし — 読み取り専用の可能性 |
| 値を変えても動かない | 本体のリモート許可、インターロック、ローカル操作盤 |
| PID がない | heater 書き込み + PID ゲイン非対応機 |
| コマンド未反映の警告 | 切断、書き込み拒否、範囲外 — サイドカー／マシン確認 |

接続自体の不具合は先に [接続トラブルシューティング](/ja/machines/troubleshooting/) を見てください。
